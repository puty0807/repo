## LockNote 0.1.2（試験版）

ロック画面から編集できる付箋。黄色い見出しと薄い罫線の入った紙の背景。上の帯をドラッグして位置を変えられる。背景を透明にしていても、畳むと黄色い「Notes」が表示され、そのままドラッグできる。本文欄は約4行から始まり、改行や折り返しで縦に広がる。

対象環境はiOS 15・Dopamine Rootless。新版のドラッグとロック中の編集は実機での確認待ち。メモ本文は端末内に保存され、ロック解除前の画面に表示される。

## P.H.S KEYBOARD 0.0.15（Beta / 実機確認待ち）

iOS 15・Dopamine Rootless向けの文字入力操作バー。切取・コピー・貼付・全選・戻す・カーソル移動・履歴、CLIPの検索・固定・お気に入り・画像・分類に対応。

- **新機能：共通履歴への任意参加。** メモ・Safari・メッセージ・メールの4アプリに加え、LINEとChatGPTでもCLIPの設定から「共通履歴へ参加する」を選べる。自動保存は別設定で、両アプリは初期状態OFF。
- LINE・ChatGPTで参加すると、既存のアプリ別履歴・画像・メタデータを可能な範囲で統合する。旧履歴は消さずに残す。参加停止するとアプリ内の個別履歴へ戻るが、共有先の履歴は削除しない。
- **プライバシー：** libSandyのアクセス許可は計6アプリの識別子に限定。全アプリ共通履歴はまだ未実装で、ほかのアプリやSpotlightは引き続き個別履歴を使用する。参加したアプリからは共通履歴全体を閲覧・変更できるので、保存する内容には注意してね。
- 0.0.14のSpotlight「テキストをスキャン」表示位置の修正、純正編集メニューとの共存、Simeji等の切替追従、LINE送信・＋ボタンとの重なり回避を維持。
- **Rootlessビルド・パッケージ検証済み／LINE・ChatGPTへの共通履歴参加は実機検証待ち。** Sileoから更新後、必要ならリスプリングし、各アプリを終了・再起動してね。異常があれば0.0.14へ戻す。
