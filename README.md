## LockNote 0.1.2（試験版）

ロック画面から編集できる付箋。黄色い見出しと薄い罫線の入った紙の背景。上の帯をドラッグして位置を変えられる。背景を透明にしていても、畳むと黄色い「Notes」が表示され、そのままドラッグできる。本文欄は約4行から始まり、改行や折り返しで縦に広がる。

対象環境はiOS 15・Dopamine Rootless。新版のドラッグとロック中の編集は実機での確認待ち。メモ本文は端末内に保存され、ロック解除前の画面に表示される。

## P.H.S KEYBOARD 0.0.10（Beta / 実機確認待ち）

対応するアプリのキーボード上部に、切り取り・コピー・貼り付け・選択・Undo・カーソル移動・コピー履歴を追加するTweak。

- LINEなどのチャット入力欄にP.H.S操作バーが重ならないよう、上へ避ける修正。余白がない場合はバーを自動的に隠す。
- `com.apple.UIKit`を対象とした試験的な注入。動作しないアプリや独自UIも存在する。
- PINNED・画像履歴・お気に入りなどのCLIP機能を継続。libSandyの共通履歴はメモ・Safari・メッセージ・メールの4アプリ限定。
- 新しいアプリでの自動記録は初期状態OFF。通常アプリのパスワード欄にもバーを表示する設計だが、自動記録はUIKitで保護入力と判定できる欄では抑止する。
- **ビルド検証済み／LINEでの実機検証は未完了。** 不安定な場合は動作確認済みの0.0.8へ戻す。
