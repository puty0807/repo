## LockNote 0.1.2（試験版）

ロック画面から編集できる付箋。黄色い見出しと薄い罫線の入った紙の背景。上の帯をドラッグして位置を変えられる。背景を透明にしていても、畳むと黄色い「Notes」が表示され、そのままドラッグできる。本文欄は約4行から始まり、改行や折り返しで縦に広がる。

対象環境はiOS 15・Dopamine Rootless。新版のドラッグとロック中の編集は実機での確認待ち。メモ本文は端末内に保存され、ロック解除前の画面に表示される。

## P.H.S KEYBOARD 0.0.14（Beta / 実機確認待ち）

対応するアプリのキーボード上部に、切り取り・コピー・貼り付け・選択・Undo・カーソル移動・コピー履歴を追加するTweak。ホーム画面のSpotlight検索欄にも対応を試験追加。

- iOS 15のホーム画面から開くSpotlight検索欄にのみ限定してSpringBoardへ表示。ロック画面・パスコード画面・通常のホームアイコン操作では非表示。既知の表示条件を判定できなければ非表示のままにする。
- 日本語・英語・絵文字・Simejiなどのキーボード切替通知に対応し、キーボード高さの変化中も操作バーを自動移動する。
- **Spotlight修正：**「全選」後に検索欄下へ純正の「テキストをスキャン」が出ても、P.H.S KEYを不必要に隠さない。純正メニューの上に余白がない場合、衝突しなければキーボード直上の位置を維持する。純正メニューが閉じれば自動復帰。
- LINEなどのチャット入力欄や送信・＋ボタンに重ならないよう、上へ避ける。余白がない場合はバーを自動的に隠す。
- `com.apple.UIKit`を対象とした試験的な注入。動作しないアプリや独自UIも存在する。
- PINNED・画像履歴・お気に入りなどのCLIP機能を継続。libSandyの共通履歴はメモ・Safari・メッセージ・メールの4アプリ限定。
- 新しいアプリでの自動記録は初期状態OFF。通常アプリのパスワード欄にもバーを表示する設計だが、自動記録はUIKitで保護入力と判定できる欄では抑止する。
- **ビルド検証済み／Spotlightでの「全選」→「テキストをスキャン」は実機再検証待ち。** 更新後はSpringBoardへ読み込むためリスプリングが必要。Spotlightの履歴はアプリ共通履歴とは別。SpringBoardに不具合が出た場合は0.0.12へ戻す。

[直接DEBを取得](https://puty0807.github.io/repo/debs/jp.puteihirose.keyboard_0.0.14_iphoneos-arm64.deb)
